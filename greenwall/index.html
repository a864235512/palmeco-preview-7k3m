Palmeco GreenWall System

把單板，變成完整牆體

Palmeco GreenWall System 地聚保溫輕質牆體系統，以 MasterBoard 為兩側面板，夾合 Geo-insulator 地聚保溫芯，適用於內外牆及 MiC 組件。

查看性能系統手冊

系統定義

不是一片板，而是一套牆體

Palmeco GreenWall System 地聚保溫輕質牆體系統，以 MasterBoard 為兩側面板，夾合 Geo-insulator 地聚保溫芯，適用於內外牆及 MiC 組件。

「兩側面板」不是「面層」：面板本身是結構與基面的組成部分，飾面另按設計需要配置。系統可按項目要求選擇面板厚度、芯材厚度及龍骨構造。
